# Security policy

## Reporting a vulnerability

Email **security@glasstrack.dev**. Please do not open a public issue or discussion for a security problem.

Include what you found, how to reproduce it and what an attacker could do with it. You will get a reply within two working days. Once a fix is out, I'm happy to credit you in the commit that fixes it if you want.

Please test only against your own workspace or your own self-hosted install. Do not access other people's data, degrade the service for others, or send spam through it.

## Supported versions

Hosted Glasstrack (glasstrack.dev) always runs the latest `main`. For self-hosted installs, fixes land on `main` only, so please keep up to date.
